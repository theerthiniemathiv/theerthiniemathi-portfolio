# Theerthiniemathi V. — Portfolio Website

A responsive personal portfolio built with plain HTML, CSS and JavaScript. The priority order is Data Analytics, AI, then Software Development.

## Run locally
1. Extract this ZIP.
2. Open the `theerthiniemathi-portfolio` folder.
3. Double-click `index.html` to preview it in your browser.
4. For local development, open the folder in VS Code and use the Live Server extension if available.

## Included features
- Responsive layout for desktop, tablet and mobile
- Mobile navigation
- Project category filters
- Interactive project case-study popups
- Download/open links for three resume versions
- Email and LinkedIn contact links
- No framework or build step required

## Publish
You can deploy this static website using GitHub Pages, Netlify or Cloudflare Pages. No backend is required for the current features.


## Technology stack accuracy
Project technology stacks are based on the supplied resumes. Methods and project capabilities are shown separately from software tools. Libraries, AI providers, databases, cloud platforms and deployment services are intentionally not claimed unless confirmed as used.
